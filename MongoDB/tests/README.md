How to make testsuite? 
* Use mikelchtermans Atlas account to save costs
* Have several json files of different dates (or dummy) in this repository; although can not test reanalysis then
* Store one fasta to be able to do reanalysis
* Have one big script which first inserts all the versions, and then does a reanalysis and inserts this new version as well
* Remove temp directory of reanalysis
* Remove everything when starting the script in order for the overviewer to be able to check if everything looks good in atlas
